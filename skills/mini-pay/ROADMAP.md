# Mini-Pay Roadmap

## Completed
- Direct ETH/STRK transfers
- Payment link generation
- QR code generation
- Invoice creation and management
- Telegram bot integration
- CLI interface
- Comprehensive documentation

## Next
- Multi-token support via ERC20 registry
- Payment link expiration and max amount limits
- Web dashboard for invoice management
- Recurring payments
- Export invoices to PDF/CSV
- Webhook notifications for payment confirmation

## Future
- Fiat on-ramp integration
- Multi-signature approval for large invoices
- Mobile app wrapper
- Analytics and reporting
